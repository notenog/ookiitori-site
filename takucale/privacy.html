プライバシーポリシー

最終更新：2026年11月21日　/　English

TakuCale（以下「本アプリ」）は、Windows向けのデスクトップ付箋ウィジェットです。運営者は notenog です。

1. 取得する情報

本アプリは、ユーザーが「Googleに接続」を選んで許可した場合に限り、次の情報にアクセスします。

  • ユーザーが同期先に選んだGoogleカレンダーの予定（タイトル・説明・日時・本アプリが付ける印）
  • カレンダーの一覧（名前とアクセス権の種類）

Googleに接続しない場合、本アプリはGoogleの情報に一切アクセスしません。また本アプリは、Googleのデータをもとに、集計したデータや匿名化したデータを作ることはありません。

要求する権限（スコープ）は次の2つだけです。

  • https://www.googleapis.com/auth/calendar.events（予定の表示・追加・変更・削除のため）
  • https://www.googleapis.com/auth/calendar.calendarlist.readonly（同期するカレンダーを選ぶため）

2. 利用目的

選ばれたカレンダーの予定を本アプリに表示し、本アプリで行った予定の追加・変更・削除をGoogleカレンダーに反映するためだけに使います。それ以外の目的には使いません。

3. 保存と第三者への提供

  • 予定のデータと、Googleへのログイン情報（トークン）は、ユーザー自身のPCの中にだけ保存されます。ログイン情報はOSの機能で暗号化されます。
  • 運営者のサーバーはありません。Googleから受け取った情報（そのままのデータも、集計・匿名化したデータも）を、運営者・第三者・データ仲介業者・広告事業者などへ送信・共有・販売することはありません。
  • 広告、行動の解析、機械学習・AIの学習には使いません。人が内容を読むこともありません。

4. データの保護

本アプリは、Googleのデータを守るために、次の仕組みを使っています。

  • 通信の暗号化：Googleとの通信は、すべてHTTPS（TLS）で暗号化しています。本アプリが通信する相手は、Googleのログインとカレンダーのサーバー（accounts.google.com・oauth2.googleapis.com・www.googleapis.com）だけです。
  • ログイン情報の暗号化：Googleへのログイン情報（アクセストークン・リフレッシュトークン）は、WindowsのOSの暗号化機能（データ保護API）で暗号化して保存します。暗号化を使えない環境では、ログイン情報を保存せず、接続もしません。パスワードは本アプリでは扱いません。
  • 安全なログインの方式：ログインには、Googleが推奨するデスクトップアプリ向けの方式（OAuth 2.0・PKCE）を使い、ログインの画面はGoogleの公式ページ（ブラウザ）で表示します。
  • 保存場所とアクセスできる人：予定のデータは、そのPCのWindowsユーザーのアプリ用フォルダにだけ保存され、OSの権限によってそのユーザーだけが読めます。外部のサーバーやクラウドには送りません。ログイン情報は、自動バックアップや書き出しのファイルにも入れません。
  • 必要最小限のアクセス：権限は上の2つだけを求め、扱うのはユーザーが選んだ1つのカレンダーの、今日の30日前から180日後までの予定だけです。

5. 保存期間と削除

  • ログイン情報は、ユーザーが接続を解除するか、Google側でアクセスを取り消すまで保存し、その時点で削除します。Google側で取り消されたことを本アプリが検知したときも、自動で削除します。
  • 予定のデータは、ユーザーがその予定を消すまで、ユーザーのPCの中に保存されます。運営者はデータを持っていないため、運営者側で保存・削除するデータはありません。

6. Limited Use

本アプリによるGoogle APIから受け取った情報の利用と他のアプリへの転送は、Limited Useの要件を含むGoogle API Services User Data Policyに従います。

7. 接続の解除とデータの削除

  • 本アプリの「接続を解除」で、ログイン情報の削除とGoogleへのアクセス取り消しを行います（TakuCaleの予定はそのまま残ります）。
  • Googleアカウントのアクセス権の画面からも、いつでも取り消せます。
  • 本アプリが保存したデータは、本アプリを削除し、アプリのデータフォルダを消すとなくなります。

8. このウェブサイトについて

このウェブサイトは、アクセス解析や広告、外部のフォント配信などを使っていません。

9. 変更

内容を変えるときは、このページを更新し、最終更新日を書き換えます。

Privacy Policy

Last updated: November 21, 2026

TakuCale ("the app") is a desktop sticky-note widget for Windows, operated by notenog.

1. Information accessed

Only if the user chooses "Connect to Google" and grants permission, the app accesses: (a) events of the one Google Calendar the user selects to sync (title, description, date/time, and markers the app adds); and (b) the list of the user's calendars (name and access role). If the user does not connect to Google, the app does not access any Google data. The app does not create any aggregated or anonymized data from Google user data.

The app requests only two scopes: https://www.googleapis.com/auth/calendar.events (to display, create, update, and delete events) and https://www.googleapis.com/auth/calendar.calendarlist.readonly (to let the user choose which calendar to sync).

2. Use

The information is used solely to display the selected calendar's events in the app and to apply the user's additions, edits, and deletions made in the app to Google Calendar. It is not used for any other purpose.

3. Storage and sharing

  • Event data and Google sign-in credentials (tokens) are stored only on the user's own PC. Credentials are encrypted using the operating system's facilities.
  • There is no developer server. We do not transmit, share, or sell information received from Google (raw, aggregated, or anonymized) to the developer or any third party, including data brokers and advertisers.
  • The information is not used for advertising, behavioral analytics, or to develop or train machine-learning or AI models, and no human reads it.

4. Data protection

The app protects Google user data with the following mechanisms:

  • Encryption in transit: all communication with Google is encrypted with HTTPS (TLS). The app communicates only with Google's sign-in and Calendar servers (accounts.google.com, oauth2.googleapis.com, www.googleapis.com).
  • Encryption of credentials at rest: Google sign-in credentials (access and refresh tokens) are encrypted with the Windows operating system's data protection API before being stored. If encryption is not available, the app does not store credentials and does not connect. The app never handles the user's password.
  • Secure sign-in: the app uses Google's recommended sign-in flow for desktop apps (OAuth 2.0 with PKCE), and the sign-in page is shown by Google in the user's browser.
  • Storage location and access control: event data is stored only in the app's folder of the current Windows user on that PC, and the operating system's permissions restrict it to that user. It is never sent to any external server or cloud service. Credentials are excluded from automatic backups and exported files.
  • Minimal access: the app requests only the two scopes above and handles only events of the one calendar the user selects, from 30 days in the past to 180 days ahead.

5. Data retention and deletion

  • Credentials are kept until the user disconnects in the app or revokes access in their Google Account, and are deleted at that point. They are also deleted automatically when the app detects that access has been revoked.
  • Event data is kept on the user's PC until the user deletes the event. Because the developer does not hold any user data, there is no data on the developer's side to retain or delete.

6. Limited Use

TakuCale's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

7. Disconnecting and deleting data

  • "Disconnect" in the app deletes the stored credentials and revokes access with Google (events already in the app remain).
  • You can also revoke access at any time at your Google Account permissions page.
  • Deleting the app and its data folder removes everything the app has stored.

8. This website

This website does not use analytics, advertising, or external font services.

If this policy changes, this page will be updated together with the "Last updated" date.
